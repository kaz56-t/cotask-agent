# CoTask Agent - AutoGen Multi-Task Orchestrator

A tool that starts up with Docker Compose and executes multiple autonomous tasks in parallel using OpenAI/Claude APIs interchangeably.

## Setup

### 1. Environment Variable Configuration

Create a `.env` file and set the following environment variables:

```bash
# OpenAI API Configuration
OPENAI_API_KEY=your_openai_api_key_here

# Anthropic API Configuration
ANTHROPIC_API_KEY=your_anthropic_api_key_here

# Langfuse Configuration (Optional)
# If Langfuse API keys are configured, LLM tracking is enabled
LANGFUSE_HOST=https://cloud.langfuse.com
LANGFUSE_PUBLIC_KEY=pk-your-public-key-here
LANGFUSE_SECRET_KEY=sk-your-secret-key-here

# Task Configuration
MAX_CONCURRENT_TASKS=3

# Database Configuration
DATABASE_URL=sqlite:///./data/sqlite.db
```

### 2. Starting with Docker Compose

```bash
docker-compose up -d
```

### 3. Accessing Services

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **API Docs**: http://localhost:8000/docs

## Development

### Backend Development

The backend code is mounted in the `./backend` directory, so changes to the code will automatically reload.

### Frontend Development

The frontend code is mounted in the `./frontend` directory, so changes to the code will automatically reload.

### Viewing Logs

```bash
# Logs for all services
docker-compose logs -f

# Logs for specific services
docker-compose logs -f backend
docker-compose logs -f frontend
```

### Stopping Services

```bash
docker-compose down
```

### Deleting Data (Warning: All data will be deleted)

```bash
docker-compose down -v
rm -rf data/
```

## Notes

- The backend container accesses the host's Docker socket (`/var/run/docker.sock`) to create independent containers for code execution
- Data is persisted in the `./data` directory
- Environment variables should be managed in the `.env` file
